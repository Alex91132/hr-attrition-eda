# HR Analytics: почему уходят сотрудники

Разведочный анализ данных об оттоке персонала (IBM HR Analytics, 1470 сотрудников, 35 признаков, 16 % отток).

## Подход

Не «посмотрим на распределения», а **бизнес-вопросы**:
1. Кто уходит? (возраст, стаж, роль, доход)
2. Что отличает ушедших? (удовлетворённость, переработки, рост)
3. Какие сегменты — зона риска?

Каждый раздел заканчивается статистической проверкой (хи-квадрат + Cramér's V для категориальных, Манн — Уитни + Cohen's d для числовых, логистическая регрессия для чистых эффектов) и выводом, пригодным для HR-решений.

## Ключевые результаты

| Фактор | Эффект | Статистика |
|---|---|---|
| **Сверхурочные** | Отток 30,5 % с переработками vs 10,4 % без — **риск в 2,9× выше** | χ² = 87,6, p < 0,001, Cramér's V = 0,24 |
| **Возраст** | До 30 лет отток 27,9 %, после 40 — 10,9 % | Cohen's d = 0,47 |
| **Первые 2 года** | Отток 27 % — критический период | Cohen's d = 0,35 |
| **Доход** | Значим только на JobLevel 1 (p < 0,001) | После контроля за уровнем — незначим |
| **Удовлетворённость** | Низкий рейтинг (1–2) удваивает риск | Разница 5,8–6,6 п.п. |
| **Модель** | Лог-регрессия, 5-fold CV | AUC = 0,797 ± 0,013 |

## Практические рекомендации для HR

1. **Контроль переработок** для сотрудников со стажем < 2 лет — самый высокий ROI вмешательства
2. **Программы удержания** для 18–30 лет — сегмент с оттоком 28 %
3. **Мониторинг удовлетворённости** как ранний индикатор — низкий рейтинг по любому параметру удваивает риск
4. **Онбординг** в первые 2 года — критический период оттока 27 %

## Методы

- Хи-квадрат + Cramér's V — ассоциация категориальных признаков с оттоком
- Манн — Уитни + Cohen's d — сравнение числовых признаков (устойчиво к ненормальности)
- Логистическая регрессия со стандартизацией — чистые эффекты после контроля за конфаундерами
- 5-fold кросс-валидация AUC — качество модели
- Сегментация риска (стаж × переработки) — карта для адресных HR-мероприятий
